## 📜 100% Privacy-First Commitment

Zento Reader operates **100% Client-side inside your browser**.  
We strictly adhere to:
- **NO** web browsing history tracking or logging.
- **NO** outbound data transmission of the URLs you visit.
- All user preferences, custom themes, and domain settings are stored securely inside your local `chrome.storage.local`.

## 🤝 How to Submit an Issue

1. Click on the **[Issues](https://github.com/zentomedia-net/zento-reader-support/issues)** tab.
2. Click **New Issue**.
3. Select the appropriate form template:
   - **🌐 Website Compatibility Request | Đề xuất tối ưu website**: If a specific blog, news outlet, documentation site, or forum exhibits low text contrast, overly dimmed media, or layout shift when Dark, OLED, or Sepia mode is active.
   - **🐛 Bug Report | Báo cáo lỗi Extension**: For shortcut unresponsive issues, popup UI glitches, or brightness slider behavior.
4. Drag and drop screenshots directly into the form for fastest diagnosis.
